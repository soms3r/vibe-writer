# Zen Scribe

A dark, minimalist, distraction-free writing canvas that runs entirely in your browser — no installation, no account, no internet required.

![Zen Scribe screenshot](https://raw.githubusercontent.com/soms3r/zen-scribe/main/screenshot.png)

---

## ✨ Features

- **Dark & Minimal** — Sleek, ultra-minimalist interface designed for focus.
- **Auto-Save** — Your writing is saved to your browser every 2 seconds. Close and come back later — it's all there.
- **Live Metrics** — Real-time word count, character count, and estimated reading time.
- **Copy Text** — One click copies your entire draft to the clipboard.
- **Download File** — Exports your draft as a timestamped `draft-YYYY-MM-DD-HHMMSS.md` file.
- **Clear Canvas** — Wipes the slate clean (with a confirmation prompt).
- **Fully Offline** — Once downloaded, everything runs locally. No servers, no sign-ups, no tracking.

---

## 📦 How to Download & Use

1. **Download the ZIP**  
   Go to the [GitHub repository](https://github.com/soms3r/zen-scribe) and click the green **Code** button, then select **Download ZIP**.

2. **Extract the folder**  
   Locate the downloaded `.zip` file on your computer, right-click it, and choose **Extract All** (Windows) or double-click it (macOS). This creates a folder called `zen-scribe`.

3. **Open `index.html`**  
   Open the `zen-scribe` folder and double-click the file named `index.html`. It will open in your default web browser.

4. **Start writing**  
   That's it. Just start typing. Everything saves automatically.

> **Tip:** To keep your drafts organised, bookmark the page or pin the tab. Your writing will be there when you come back.

---

## 🧰 For Developers

Zen Scribe is a single, self-contained HTML file. No build tools, no frameworks, no dependencies. To customise it, just edit `index.html` in any text editor.

- CSS variables in the `:root` block control the colour palette and typography.
- JavaScript logic lives in the `<script>` tag at the bottom.
- Drafts are stored in the browser's `localStorage` under the key `zen-scribe-draft`.
